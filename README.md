# A/L Chemistry Unit 02 – Interactive Tamil Course

Built with React + TypeScript + Vite. Includes:
- Interactive Lewis-structure walkthroughs (HCN, CH4, NH3, H2O, CO2, CH3NH2, C2H4)
- Step-by-step electron counting and lone-pair explanations
- VSEPR calculator and shape/geometry reference table
- Hybridisation overview and orbital descriptions
- Interactive C–N single, double and triple bond overlap explanations
- σ / π conceptual diagrams and self-check questions

## Run
1. Install Node.js LTS.
2. Extract this project.
3. Open a terminal in this folder.
4. Run `npm install`
5. Run `npm run dev`
6. Open the local Vite URL shown in the terminal.

## Build and publish
Run `npm run build`. Publish the generated `dist` folder using Netlify, Vercel or GitHub Pages.

## Chemistry notes
- Multiple bonds count as one VSEPR electron domain.
- Typical amine C—N single bond: sp3–sp3 σ overlap (check the actual atom environment).
- Imine C=N: commonly sp2–sp2 σ plus one p–p π overlap.
- Nitrile C≡N: sp–sp σ plus two p–p π overlaps.
- The orbital drawings are conceptual, not to scale.
- The hybridisation notation follows traditional A/L teaching models; follow the exact notation used in your class resource book.
